## Practical selection rules
- Need custom visuals or interactions: begin in nodes/edges/interaction sections.
- Need automatic positioning: begin in layout section and pair with ecosystem layout libraries.
- Need collaborative or editor-like UX: begin in whiteboard + interaction Pro examples.
- Need screenshots/export pipelines: begin in misc download-image and SSR docs.
