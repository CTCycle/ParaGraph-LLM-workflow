# PG-T1-03 — Configuration Persistence and Secret Redaction

- Date: 2026-09-23
- Status: `PASS`
- Failure class: `STATE` — the first repeated-update attempt found a database flush-order defect; fixed and retested.

## Scope

Validate configuration and named-profile reads/writes through the HTTP routes,
including persisted credentials, redacted responses, and preservation of a
saved key when the client submits a redacted payload. External provider
connectivity and live browser behavior are outside this scope.

- The configuration integration test created and migrated its own SQLite

- Node.js `22.23.1`, npm `10.9.8` for the focused frontend unit test.

## Finding and fix

The first repeated active configuration update failed with SQLite
`UNIQUE constraint failed: provider_configurations.session_id,
provider_configurations.provider`. `ConfigurationRepository.save_configuration`
now flushes pending deletions before inserting replacement provider rows. The
regression test covers active configuration updates and profile round trips.
