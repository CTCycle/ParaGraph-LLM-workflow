## Finding and regression

The new real-repository update flow exposed a SQLite uniqueness failure when a
replacement provider row was inserted before SQLAlchemy flushed the old row's
deletion. The repository now flushes pending provider deletions before adding
replacement rows. The final focused backend run passed all 11 selected tests,
including configuration repository and generated-contract checks.
