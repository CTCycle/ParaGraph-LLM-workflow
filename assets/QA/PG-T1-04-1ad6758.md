## Scope

Validate browser-local workflow graph save, reload, and route/history
navigation persistence against the current revision. A deterministic local
Prompt-to-Text Output run was used to observe the relationship between graph
state and runtime output; model providers were not used.

- Codex in-app Browser; browser engine version is not exposed by the tool.

- The browser began with an empty workflow on this test origin.

## Remaining decision

`workflow.editor.graph` remains validated for browser-local graph state. The
runtime output disappearing after reload is observed, but current product
requirements do not say whether that transient output should persist. Keep
that item in validation debt until the product behavior is decided; if output
must persist, add a focused regression and update the persistence boundary.
Provider-backed execution and Chat history are outside this slice.
